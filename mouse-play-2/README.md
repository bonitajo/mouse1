# 마우스야 놀자 2.0

기존 「10월사격.html」의 하늘, 구름, 풀밭과 큰 새의 클릭 방식을 참고한 네 가지 마우스 연습 게임입니다. HTML/CSS/JavaScript만 사용하며 별도 설치나 빌드가 필요 없습니다.

## 실행

1. ZIP 압축을 풉니다.
2. `index.html`을 Chrome 또는 Edge로 엽니다. `assets`, `js`, `style.css`를 같은 폴더에 유지합니다.
3. 이름 → 게임 → 난이도를 선택합니다. 모든 게임은 150초입니다.

교실에서는 GitHub Pages 주소로 실행하는 방식을 권장합니다. 파일을 직접 열면 브라우저 정책에 따라 기록 저장 동작이 달라질 수 있습니다. 저장이 막혀도 게임은 진행되며 결과 화면에 저장 불가를 표시합니다.

## 조작

| 게임 | 조작 | 점수 |
|---|---|---|
| 새 사냥 | 새를 클릭 | 큰 새 10점 · 중간 새 20점 · 작은 새 30점 |
| 사진 퍼즐 | 오른쪽 조각을 왼쪽의 정답 위치로 끌어 놓기 | 조각마다 10점 |
| 풍선 터뜨리기 | 풍선을 클릭 | 큰 풍선 10점 · 중간 풍선 20점 · 작은 풍선 30점 |
| 틀린그림찾기 | 두 그림에서 다른 곳을 클릭 | 한 곳마다 10점 |

초급 퍼즐은 6조각(3×2), 중급은 9조각(3×3)입니다. 퍼즐을 완성하면 다음 사진으로 이어집니다. 실수에 따른 감점은 없습니다. 토끼 게임은 요청에 따라 제외했습니다. 틀린그림찾기는 초급 3곳, 중급 5곳을 찾습니다. 어느 쪽 그림을 눌러도 같은 정답으로 처리하고, 이미 찾은 곳은 중복 득점되지 않습니다. 모두 찾으면 다음 그림으로 넘어갑니다. ‘그림 크게’는 그림을 세로로 배치해 확대합니다. 좁은 화면에서는 자동으로 세로 배치됩니다.

소리는 첫 화면의 큰 버튼으로 켭니다. 배경음과 효과음은 브라우저에서 합성합니다. 소리와 글자 크기 설정은 브라우저에 저장합니다. 별도 음원이나 외부 글꼴 요청이 없습니다. 전체 화면은 브라우저 지원 여부에 따라 작동합니다.

## 기록과 제한

- 현재는 **이 브라우저의 로컬 순위**입니다. 여러 컴퓨터 사이에 공유되지 않습니다.
- 날짜(한국 시간), 게임, 난이도, 이름을 기준으로 최고 점수를 저장합니다. 이름이 같으면 같은 참가자로 처리합니다.
- 상위 10명과 본인 순위를 표시합니다. 동점은 이름순으로 표시합니다.
- 새로운 기록을 저장할 때 지난 날짜의 기록을 정리합니다. 날짜가 바뀌면 오늘의 순위에 이전 날짜를 표시하지 않습니다.
- 새로고침 시 이름을 다시 입력합니다. 게임 간 이동과 ‘처음으로’에서는 이름을 유지한 채 게임 선택 화면으로 이동합니다. 이름을 바꾸려면 게임 선택 화면의 ‘이름 변경’을 누릅니다.
- 진행 중 게임 선택/처음으로 버튼을 누르면 현재 판을 종료하며 미완료 점수는 저장하지 않습니다.
- 종료 기준은 실제 시작 시각에서 150초입니다. 다른 탭에 머물러도 시간은 흐르고 돌아올 때 종료 여부를 확인합니다. 브라우저가 정지된 동안 결과 화면 표시 자체는 즉시 실행될 수 없습니다.
- 일반적인 교실 마우스 사용을 위한 게임입니다. 클라이언트 점수는 개발자 도구로 조작할 수 있어 공식 대회 검증에 적합하지 않습니다.

## 소스 구조

`js/core.js`: 점수 기록, 날짜, 오디오, 이벤트와 애니메이션 정리 도구.

`js/app.js`: 이름/게임/난이도 화면, 공통 타이머, 결과 화면.

`js/targets.js`: 새 사냥과 풍선. `js/puzzle.js`: 사진 퍼즐. `js/differences.js`: 틀린그림찾기.

새와 풍선은 120/95/75픽셀의 세 크기로 등장하며 각각 10/20/30점을 줍니다. 초급과 중급은 이동 속도를 다르게 적용합니다. 목표물에는 점수를 표시하지 않고, 맞힌 뒤의 성공 효과에만 획득 점수를 표시합니다. 기존 게임 보관본은 변경하지 않았습니다.

## GitHub Pages에 올리기

기존 사이트를 유지하려면 저장소에 `mouse-play-2` 같은 새 폴더를 만들고 이 폴더의 파일을 모두 올립니다. 현재 Pages가 기본 브랜치의 루트를 제공한다면 `기존주소/mouse-play-2/`에서 실행됩니다. 새 저장소를 사용할 때에는 Settings → Pages에서 배포 브랜치와 루트 폴더를 지정합니다. 실제 배포 결과와 권한에 따라 주소와 설정을 확인해야 합니다.

## 온라인 순위 준비

온라인 데이터베이스는 아직 생성하거나 연결하지 않았습니다. 계정이나 키를 임의로 만들지 않았습니다. 상세한 연결 설계와 필요한 절차는 `ONLINE-RANKING.md`에 있습니다.

## 2026-10-23 수업 반영

새 사냥 초급은 원본의 속도와 등장 간격을 60fps 기준의 시간 단위로 환산했습니다. 시작부터 끝까지 새의 기본 속도는 60→108픽셀/초이며 원본의 크기별 속도 배수와 무작위 변동도 적용합니다. 풍선 초급은 36→64.8픽셀/초로 상승합니다. 두 게임 모두 중급 이동 속도는 같은 시점 초급의 1.5배입니다. 등장 간격은 약 2.5초에서 0.67초까지 서서히 줄어듭니다. 화면이 과도하게 복잡해지지 않도록 동시 목표물은 7개로 제한합니다. 크기별 점수와 150초 제한은 유지합니다.
