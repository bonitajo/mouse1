# 검증 결과

검증 환경: Windows, 설치된 Chrome의 자동화 브라우저. 2026-10-17.

## 실행하여 통과한 항목

- 빈 이름과 공백만 입력했을 때 시작 차단.
- 네 게임의 초급·일반 총 8가지 조합에서 화면과 02:30 타이머 시작.
- 새 클릭 득점과 제거된 새에 대한 중복 득점 방지. 겹친 새는 각각 한 번씩 득점.
- 일반 풍선 클릭 득점.
- 초급 퍼즐 4조각의 실제 포인터 드래그, 정답 위치 자석 판정, 완성 후 다음 문제 전환, 원본 사진 창 열기·닫기.
- 초급 토끼의 실제 포인터 이동, 당근 도착 50점, 새 길 전환, 길 이탈 시 복귀, 큰 순간 이동으로 도착하는 방법 차단.
- 브라우저 시계를 151초 뒤로 이동시켰을 때 자동 종료와 결과·순위 표시. 실제 150초 동안 대기하는 검증은 하지 않음.
- 다시 하기 점수·시간 초기화, 게임 선택으로 이동 시 이전 캔버스 제거.
- 공통 정리 도구를 해제한 뒤 이벤트, 예약 작업, 애니메이션 콜백이 실행되지 않음.
- 소리 켜기·끄기 버튼과 상태 전환.
- 최고 기록만 갱신하고 난이도별 기록 분리.
- 브라우저 저장 공간의 쓰기가 차단되어도 예외 없이 저장 실패 반환.
- 1920, 1366, 390픽셀 너비에서 게임 선택 화면의 큰 글자 적용 시 가로 넘침 없음.
- 새로고침 시 시작 화면 정상 표시.
- HTTP 로컬 서버와 HTML 파일 직접 열기 실행.
- 기본 조작 검증 중 브라우저 JavaScript 예외 없음.
- 게임 선택 화면과 새 사냥 화면을 스크린샷으로 확인.
- GitHub Pages 배포 성공과 실제 공개 주소 HTTP 200 확인.
- 공개 주소에서 일반 퍼즐 6조각을 모두 끌어 맞춰 60점 확인. 완성 후 다음 사진 전환과 두 사진의 원본 보기 로딩 확인.
- 공개 주소의 검증 과정에서 리소스 요청 실패와 JavaScript 예외 없음.
- 기존 접속 주소에서도 HTTP 200, 일반 퍼즐 6조각 완성과 사진 로딩을 확인. 기존 게임 보관 주소도 HTTP 200 확인.

## 아직 확인하지 않은 항목

- 여러 실제 교실 컴퓨터와 여러 브라우저에서 장시간 반복 사용.
- 실제 150초 대기와 컴퓨터 절전·시계 수동 변경 상황.
- 일반 토끼 길의 전체 수동 완주.
- 스피커로 들리는 음질·음량, 운영체제 음소거 상태.
- 전체 화면 권한과 모든 브라우저의 전체 화면 동작.
- 게임 진행 중 모든 화면 크기의 모든 조작. 작은 화면에서 세로 스크롤은 허용됨.
- 실제 메모리 프로파일링과 수백 회 전환에 대한 장기 자원 검사.
- 온라인 순위 서버 장애와 여러 컴퓨터 동시 기록. 현재 서버 연결 자체가 없으며 로컬 기록만 제공.
- 실제 고령 학습자의 사용성 평가.

이번 검증은 오류가 없음을 보증하지 않습니다. 수업 전 사용 모니터에서 네 게임을 한 번씩 실행해 보세요.
