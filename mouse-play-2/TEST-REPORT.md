# 수정본 검증 결과 — 2026-10-18

검증 환경: Windows, 설치된 Chrome을 이용한 자동화 브라우저. 변경 후 로컬 HTML 파일에서 실행한 결과입니다.

## 이번 수정에서 실행해 통과한 항목

- 토끼 게임 제외 후 게임 선택 카드 3개 표시.
- 새와 풍선의 큰/중간/작은 대상이 각각 120/95/75픽셀로 생성되고, 명중 시 10/20/30점 적용.
- 대상 아래 점수와 명중 효과의 점수가 일치하며 제거된 대상에는 중복 득점 없음.
- 초급 퍼즐 6조각을 실제 포인터 드래그로 완성하고 60점 확인.
- 중급 퍼즐 9조각을 실제 포인터 드래그로 완성하고 90점 확인.
- 게임 진행 중 ‘처음으로’ 클릭 시 이름을 유지한 게임 선택 화면 표시.
- 브라우저 시각을 151초 이동시켜 종료한 뒤, 결과 화면의 ‘처음으로’도 게임 선택으로 이동.
- 게임 선택의 ‘이름 변경’으로 이름 입력 화면 접근.
- 1920·1366·390픽셀 너비의 게임 선택 화면에 가로 넘침 없음.
- 게임 선택 화면 스크린샷 확인.
- 검증 중 JavaScript 예외 없음.

## 이전 버전에서 검증한 공통 기능

빈 이름·공백 시작 차단, 다시 하기 초기화, 이벤트·예약 작업·애니메이션 정리, 소리 버튼 전환, 최고점 갱신과 난이도 분리, 저장 공간 차단 시 예외 없이 실패 반환, 새로고침, 원본 사진 보기와 사진 전환을 확인했습니다. 변경하지 않은 모든 공통 기능을 이번에 다시 검사한 것은 아닙니다.

## 아직 확인하지 않은 항목

- 실제 150초 대기와 컴퓨터 절전·시계 수동 변경.
- 여러 교실 컴퓨터·브라우저에서 장시간 반복 사용과 메모리 프로파일링.
- 실제 스피커의 음질·음량과 모든 브라우저의 전체 화면 권한.
- 모든 화면 크기에서 게임 진행 중 모든 조작.
- 고령 학습자의 실제 사용성 평가.
- 온라인 순위 동시 접속과 서버 장애. 온라인 연결 없이 브라우저 기록만 제공합니다.
